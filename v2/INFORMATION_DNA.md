## The nine axioms (the DNA strands)

| # | Name | Statement | What it is in the lens |
|---|------|-----------|------------------------|
| RD1 | Null | `0 : 𝔇` | the empty retention — a start exists |
| RD2 | Generation | `x:𝔇 ⇒ σx:𝔇` | every retained state can take one more step |
| RD3 | Null is no transition | `σx ≠ 0` | a step never erases back to nothing — time has a direction |
| RD4 | Retention = injectivity | `σx = σy ⇒ x = y` | distinct histories STAY distinct — memory; the arrow of records |
| RD5 | Induction | `[φ(0) ∧ ∀x(φ(x)→φ(σx))] ⇒ ∀x φ(x)` | what holds at the start and survives every step, holds everywhere — the engine of all proof |
| RD6 | Concat base | `x ⊕ 0 = x` | joining nothing changes nothing |
| RD7 | Concat step | `x ⊕ σy = σ(x ⊕ y)` | histories compose step-by-step — addition is retained walking |
| RD8 | Layer base | `x ⊗ 0 = 0` | zero layers retain nothing |
| RD9 | Layer step | `x ⊗ σy = (x ⊗ y) ⊕ x` | layered retention — multiplication is repeated re-retention |

Defined from the DNA alone: the retention order `x ⪯ y :⇔ ∃z (x⊕z = y)` — "earlier
in retention" — which is well-founded (Coq: no infinite descent).
