## 2. The solve loop Ω_all (extends Ω_phil from 7 to 8 steps)

1. **TRANSLATE** (mandatory, new): rewrite the whole problem using the dictionary
   only. Any residue that resists translation is itself a finding — name it and
   give it a dictionary row + verdict class.
2. **Grammar gate + Ω_∞:** is the translated question well-formed? Which infinity
   (I1–I4) was injected, if any? Ill-formed absolute forms are dissolved here, not
   answered.
3. **Locate:** whose τ_c, which step, which readout policy Π is doing the cutting.
4. **Bridge audit:** every imported term keeps its ledger verdict (DERIVED /
   FORCED / DEFINITIONAL-RELABEL / POSITED / BORROWED-SCALE / OPEN); each bridge
   assumption downgrades Th → Dr.
5. **Residual form:** write the problem as a residual to descend (which r, which W)
   where possible.
6. **Identifiability gate:** before claiming an answer, check the answer is in the
   row space of the available records — a null-space question gets "structurally
   unanswerable from these records" as its ANSWER, not a guess (LTP4 discipline).
7. **Answer with tag:** the solved readout, tagged Th_coqc / finite_diagnostic /
   Dr / Open — never bare.
8. **TRANSLATE BACK + falsifier:** return the readout in the asker's vocabulary,
   with the tier attached and the falsifier of the answer itself stated.

## 3. Worked micro-example (compressed)

**Foreign form:** "Why do two rival measurements of the universe's expansion rate
disagree?"
**Step 1 translate:** two knowers with different grammars A₁ (early-universe
records) and A₂ (nearby-ladder records) each descend V to a settled readout of the
same world-configuration θ; their readouts of one coordinate disagree.
**Steps 2–6:** no infinity injected in the question itself (the continuum enters
only inside A₁'s model steps — flag as POSITED); the identifiability gate asks
whether the disagreeing coordinate is separately in the row space of each record
set, or only a combination of it (the book's own binding example: records identify
GM, never G and M). If a null direction is load-bearing, the "tension" translates
to: *the two grammars cut the same smooth world at different Π along a
poorly-identified direction* — a readout-side artifact candidate — and the honest
output is which extra record would make the direction identifiable.
**Step 7 tag:** the translation itself is `Dr`; deciding artifact-vs-world requires
running the numbers (a planned AP1 `finite_diagnostic`, not yet run — so the
verdict here stays **Open**).
**Step 8 falsifier:** exhibit that the disagreeing coordinate IS separately
identifiable in both record sets at the stated precision; then the artifact reading
dies and the tension translates back as a genuine world-side residual (new physics).
